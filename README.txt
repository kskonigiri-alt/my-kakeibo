MY 家計簿 iPhone向けPWA試作品

1. このフォルダをHTTPS対応の静的ホスティングに配置してください（index.html, manifest.webmanifest, service-worker.js, icon画像）。
2. iPhoneのSafariで公開URLを開き、共有 → ホーム画面に追加。
3. データは端末のブラウザ内（localStorage）に保存されます。クラウド同期とログインは未実装です。
4. 設定からJSONバックアップを定期的に書き出してください。
5. クラウド保存を実装するには、クラウドサービスのプロジェクト作成・認証・データベース・アクセス制御の設定が必要です。

注意：既存のkakeibo.htmlを別のURLで開いて入力したデータは自動移行されません。元の画面でバックアップを出力し、公開版で復元してください。
